    About this directory

    The list comes from Colombo Stock Exchange listings and a hand-curated list of Sri Lankan tech employers. Links go straight to each company's own site. VacancyFinder doesn't host or copy job adverts, so always check the company's page for current openings and how to apply.

    Many companies don't publish a careers page. For those, the website is the best place to start. Where neither is known, the company is still listed so you can find it by name.

    Spotted a wrong or missing link? Open an issue on GitHub.
